# design_v2

這是一套響應式介面的底層設計系統。本倉目前只有邏輯、規範與 token，沒有畫面、沒有元件實作、沒有品牌主題。

規範由兩部分一起成立：

| 檔案 | 職責 |
|---|---|
| [SPEC.md](SPEC.md) | 行為與約束。定義介面如何隨寬度、高度、容器與輸入方式變化。 |
| [tokens/](tokens/) | 數值。間距、字級、斷點、色彩、尺寸、圓角、海拔、動效與層級。 |

`tokens/index.json` 的 `version` 是這套底層的版本。規則與數值衝突時，先改正衝突，再使用。畫面與元件實作不得另寫一套斷點或色值。

閱讀順序：本頁，然後 `SPEC.md`，需要數值時再查對應的 token 檔。
